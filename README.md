# ComfyUI Custom Node Manager

ComfyUI 顶栏插件管理器，用来管理 `custom_nodes` 里的 Git 仓库和 Comfy Registry 包。它不是 ComfyUI-Manager 的替代品；如果两个都开着，请尽量只用其中一个做安装/卸载，避免互相覆盖。

- 打开后先显示本机已安装列表。远程版本要点「检查更新」，或在管理中心打开定时检查——定时检查由 ComfyUI 服务端在后台执行，不需要保持网页开着。
- 「安装插件」支持 GitHub 搜索/克隆、任意 git 地址，以及 Comfy Registry 官方市场包。
- 安装和更新会安装 `requirements.txt`，没有该文件时会安装 `pyproject.toml` 的依赖；依赖预检会标注可能降级共享依赖的包。
- 更新时先备份；依赖安装失败会自动回滚。也可在管理中心手动回滚或删除备份（备份按插件保留最近几份，超出的会自动清理，不会无限占用磁盘）。
- 安装、更新、禁用、卸载后必须重启 ComfyUI 才生效。未重启时顶栏会一直提示。
- 可禁用插件、忽略更新、把 Git 插件固定到某个提交、勾选多个插件批量更新，或对损坏的插件执行「重新安装」。不同插件的更新/重新安装互不阻塞，可以同时进行几个。
- 插件列表和管理中心都能看到每个插件/备份占用的磁盘空间。
- 状态一栏可以点：点「可更新/落后 N 次」能看到具体落后了哪些提交（含改动文件）；点「有本地修改」能看到本地实际改了什么内容（逐文件 diff）。
- 关闭管理器窗口或刷新页面后，重新打开会自动接回后台仍在运行的安装/更新任务。
- 频繁搜索 GitHub 时，可在 ComfyUI 启动环境设置 `GITHUB_TOKEN` 或 `GH_TOKEN`。

Restart ComfyUI after installing or updating plugins.
